silky spawners

spawners are usually a one-way block. once one is mined, it is gone. this small script changes that for players using a silk touch pickaxe.

when a player breaks a spawner, the script checks the tool in their hand. if it has silk touch, the spawner drops as an item instead of breaking normally. the dropped item keeps the type of creature the spawner made, so a zombie spawner stays a zombie spawner.

this is made for a server that uses denizen and supports spawner items. test it on a backup world first, especially if players can trade or sell spawners.

how it works

the first check keeps normal pickaxes working the way players expect. no silk touch means the script stops and leaves the block break alone.

after that, it reads the spawner at the broken block. the final line gives back a new spawner item with the same creature type and a clear display name. it is only a few lines, but it gives rare spawners a real reason to be protected and collected.
